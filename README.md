# Anti-theft-system
라즈베리파이와 파이썬 활용한 IoT 프로젝트


최근 무인 점포가 늘어난다는 사실을 주목했고, 이와 관련된 제품을 개발하기 위해서 떠올린 것이 도난 방지 시스템입니다.

일반적인 CCTV의 경우에는 물건을 구별하는 능력이 없습니다. 

이 제품을 사용하면 모션 인식을 통해 가게에 판매를 위해 배치된 물건과 판매하지 않는 물건을 구별할 수 있습니다.
이를 활용할 방안은 매우 다양합니다

재고를 확인하다 문제가 발생했을 때 물건을 구별하여 사라짐을 기억해두기 때문에 금방 문제를 해결할 수 있습니다.
판매물품과 판매하지 않는 물품의 도난을 방지할 수 있습니다

사람을 감지하는 능력도 갖추고 있기에 활용 방안은 무궁무진하다고 보여집니다.


1차 수정 사항

Q. 어두운 곳에서 카메라가 인식하지 못해 도난을 당한다면 어떻게 하실 건가요?

A. 저희는 무인 점포를 위주로 생각하며 제품을 개발했습니다. 따라서 빛이 부족한 환경을 고려하지 않고 있었습니다.
저희는 이 질문을 해결하기 위해 LED 와 조도 센서를 사용하겠습니다.
어두운 곳을 감지하는 조도 센서를 사용해서 카메라 근처에 일정량 이하의 빛이 감지된다면
LED가 켜지며 필요한 빛을  확보한 뒤에 동작을 이어서 진행하겠습니다
